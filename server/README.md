# Woodmax2026 Server

Express-based API server providing ecommerce endpoints.  Initially proxies to Supabase; later will contain full business logic.

## Commands

- `pnpm install` – install dependencies
- `pnpm run dev` – start server with ts-node
- `pnpm run build` – compile TypeScript to `dist`
- `pnpm run start` – run compiled server

### Environment variables
See `.env.example`.
